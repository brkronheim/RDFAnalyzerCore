And follow instructions in README file.

Run year 	Production version 	Package 	Manual 	Remark
2016 	Prompt(80X) 	rochcor80x_070616v2.tgz 	Manual for this version (Same with 76x release, but class name is changed from "rochcor2015" to "rochcor2016") 	Correction for 2016 Prompt(80x) sample. 2.66/fb data is used. Report for this version in Muon POG working meeting (July.13th, 2016). The correction only contains the statistical uncertainty of the correction.
2015 	ReReco(76X, time dependence) 	rochcor76x_tdep.tgz 	Manual for this version 	Correction for Rereco(76x) sample. Since data has time dependence, the correction is extracted to consider time dependence in data (before and after run=260528). The instruction is same with previous version (76x), but need to add RunNumber in data. The file naming is same with previous version. Report for this version in Muon POG (May.18th, 2016) is lined at HERE. The correction for Run2 data only contains the statistical uncertainty of the correction. Latest version of Rochester correction for the 2015 dataset, it is recommended to switch to this one, and switch to 76X in case any of the old ones was still used.
ReReco(76X) 	rochcor76x_v2.tgz 	Manual for this version 	Preliminary result for Run2 25ns Rereco(76x) sample. The package for resolution function is changed compared to Prompt version. Please check the manual. Report for this version in Muon POG (Mar.9th, 2016) is lined at HERE
PromptReco(74X) 	rochcor2015_2fb.tgz 	Manual for this version 	First preliminary result for Run2 25ns PromptReco sample. Report for this version in Muon POG is linked at HERE If an accurate knowledge of the momentum corrections is needed is recommended to switch to 76X.

REMARK : 76X release is updated for systematic uncertainty assignment (error of global scale factor was wrong). The release version is v2. The change doesn't affect on the central result at all. The systematic error from smearing the central correction value will be reduced in v2, especially near Z peak region.
