Recommendations for the 13 TeV UL data analysis, Run2016 (106X) (APV and non-APV runs)

In the following table, the JetID criteria for AK4CHS and AK4 PUPPI jets are listed. The criteria both for AK4CHS and AK4 PUPPI jets are valid for all run eras 2016B-H.

Please note: For AK8 jets, the corresponding (CHS or PUPPI) AK4 jet ID should be used.

For AK4CHS, the efficiency is more than 98-99% for all eta regions, whereas the background rejection is more than 98% for |η|<3. Analyses that use simulated AK4CHS jets should use the same criteria and no scale factors are required.

Please see the Analysis Note with all the completed studies.

For AK4 PUPPI, the efficiency is more than 98-99% for all eta regions, whereas the background rejection is more than 98% for |η|<2.7. Analyses that use simulated AK4 PUPPI jets should use the same criteria and no scale factors are required.

For more details on the performance of the AK4CHS JetID criteria on the running periods that were affected by the APV issue see here.

For more details on the performance of the AK4 PUPPI JetID criteria on the running periods that were affected by the APV issue see here.

For more details on the performance of both the AK4CHS and AK4 PUPPI JetID criteria on the running periods that were not affected by the APV issue see here.

We generally recommend to apply the jet ID criteria listed below including those marked as "for LepVeto" for all analyses. For analyses that perform any special cleaning or selections between jets and leptons, the jet ID can also be applied without the vetoing on leptons to avoid possible biases.

A general good practice for jet analyses is to make plots of the observables used for jet ID (and not only the boolean). They help checking if there is residual noise left after all ID/analyses selections in the specific analysis phase space.

Usage with NanoAOD

NanoAODv9

In NanoAODv9, there is a flag called Jet_jetId corresponding to the different working points described in the recommendations above. If a jet has jetId value equal to 6, it means that the jet passes both tight and tightLepVeto working points. When it is equal to 2, then it passes tight but fails tightLepVeto.

        jetId==2 means: pass tight ID, fail tightLepVeto
        jetId==6 means: pass tight and tightLepVeto ID. 

Reminder that the Jet collection is the AK4 CHS jet collection

NanoAODv15

In NanoAODv15, the Jet collection is the AK4 Puppi jet collection and Jet_jetId flag has been removed. Analyzers need to implement the jet Id selection. The correction-lib json files to implement the jet Id is currently being prepared. Alternatively, analyzers can implement the selections in their analyses by following the pseudocodes below:

a) 2016

bool Jet_passJetIdTight = false;
if (abs(Jet_eta) <= 2.4) 
  Jet_passJetIdTight = (Jet_neHEF < 0.9) && (Jet_neEmEF < 0.9) && (Jet_chMultiplicity+Jet_neMultiplicity > 1) && (Jet_chHEF > 0.0) && (Jet_chMultiplicity > 0);
else if (abs(Jet_eta) > 2.4 && abs(Jet_eta) <= 2.7)
  Jet_passJetIdTight = (Jet_neHEF < 0.98) && (Jet_neEmEF < 0.99);
else if (abs(Jet_eta) > 2.7 && abs(Jet_eta) <= 3.0)
  Jet_passJetIdTight = Jet_neMultiplicity >= 1;
else if (abs(Jet_eta) > 3.0)
  Jet_passJetIdTight = (Jet_neMultiplicity > 2) && (Jet_neEmEF < 0.9);

bool Jet_passJetIdTightLepVeto = false;
if (abs(Jet_eta) <= 2.4) Jet_passJetIdTightLepVeto = Jet_passJetIdTight && (Jet_muEF < 0.8) && (Jet_chEmEF < 0.8);
else Jet_passJetIdTightLepVeto = Jet_passJetIdTight;

b) 2017 & 2018

bool Jet_passJetIdTight = false;
if (abs(Jet_eta) <= 2.6) 
  Jet_passJetIdTight = (Jet_neHEF < 0.9) && (Jet_neEmEF < 0.9) && (Jet_chMultiplicity+Jet_neMultiplicity > 1) && (Jet_chHEF > 0.0) && (Jet_chMultiplicity > 0);
else if (abs(Jet_eta) > 2.6 && abs(Jet_eta) <= 2.7)
  Jet_passJetIdTight = (Jet_neHEF < 0.90) && (Jet_neEmEF < 0.99);
else if (abs(Jet_eta) > 2.7 && abs(Jet_eta) <= 3.0)
  Jet_passJetIdTight = Jet_neHEF < 0.9999;
else if (abs(Jet_eta) > 3.0)
  Jet_passJetIdTight = (Jet_neMultiplicity > 2) && (Jet_neEmEF < 0.9);

bool Jet_passJetIdTightLepVeto = false;
if (abs(Jet_eta) <= 2.7) Jet_passJetIdTightLepVeto = Jet_passJetIdTight && (Jet_muEF < 0.8) && (Jet_chEmEF < 0.8);
else Jet_passJetIdTightLepVeto = Jet_passJetIdTight;

PUPPI jets multiplicities

If you are using ULMiniAODv2 for your analysis, note that for PUPPI jets, weighted multiplicties (of type float) were used:

jet->userFloat("patPuppiJetSpecificProducer:puppiMultiplicity")
jet->userFloat("patPuppiJetSpecificProducer:neutralPuppiMultiplicity")

Jet fractions

Note: All fractions are calculated with the raw/uncorrected energy of the jet (only then they add up to unity). So the PF JetID has to be applied before the jet energy corrections and jet energy resolution smearing (discussed here). To do this on a MINIAOD jet, you can get them as:

 NHF  = pfjet->neutralHadronEnergyFraction();
 NEMF = pfjet->neutralEmEnergyFraction();
 CHF  = pfjet->chargedHadronEnergyFraction();
 MUF  = pfjet->muonEnergyFraction();
 CEMF = pfjet->chargedEmEnergyFraction();
 NumConst = pfjet->chargedMultiplicity()+pfjet->neutralMultiplicity();
 NumNeutralParticles =pfjet->neutralMultiplicity();
 CHM      = pfjet->chargedMultiplicity(); 

OR you can refine them (not recommended)

            auto CHF          = jet.chargedHadronEnergy() / jet.correctedP4(0).E()  ;  
            auto NHF          = jet.neutralHadronEnergy() / jet.correctedP4(0).E()  ;  
            auto CM           = jet.chargedMultiplicity()  ;                  
            auto NM           = jet.neutralMultiplicity()  ;                  
            auto NEF          = jet.neutralEmEnergy() / jet.correctedP4(0).E()  ;      
            auto CEF          = jet.chargedEmEnergy() / jet.correctedP4(0).E()  ;      
            auto MUF          = jet.muonEnergy() / jet.correctedP4(0).E()  ;           
            auto NumConst = jet.numberOfDaughters() ;

nanoAOD Flags

In nanoAOD format, there is flag called Jet_jetId corresponding to the different working points described in the recommendations above. If a jet has jetId value equal to 6, it means that the jet passes both tight and tightLepVeto working points. When it is equal to 2, then it passes tight but fails tightLepVeto.

        jetId==2 means: pass tight ID, fail tightLepVeto
        jetId==6 means: pass tight and tightLepVeto ID. 

Please note that there is a bug in Nanov12 & Nanov13 & Nanov14 and a special recipe is needed in order to obtain the correct JetID recommendations:

Nanov12:

bool Jet_passJetIdTight = false;
if (abs(Jet_eta) <= 2.7) Jet_passJetIdTight = Jet_jetId & (1 << 1);
else if (abs(Jet_eta) > 2.7 && abs(Jet_eta) <= 3.0) Jet_passJetIdTight = (Jet_jetId & (1 << 1)) && (Jet_neHEF < 0.99);
else if (abs(Jet_eta) > 3.0) Jet_passJetIdTight = (Jet_jetId & (1 << 1)) && (Jet_neEmEF < 0.4);

bool Jet_passJetIdTightLepVeto = false;
if (abs(Jet_eta) <= 2.7) Jet_passJetIdTightLepVeto = Jet_passJetIdTight && (Jet_muEF < 0.8) && (Jet_chEmEF < 0.8);
else Jet_passJetIdTightLepVeto = Jet_passJetIdTight;

Nanov13, NanoV14 and NanoV15: Please use the dedicated json file developed. Please find an example here. Here is a pseudocode if you want to manually implement the jet Id selection with NanoAOD:

bool Jet_passJetIdTight = false;
if (abs(Jet_eta) <= 2.6)

  Jet_passJetIdTight = (Jet_neHEF < 0.99);
else if (abs(Jet_eta) > 3.0)

Introduction

PileupJet ID is a BDT trained discriminator aiming to discriminate prompt jets from pile-up jets. It uses several jet shape and kinematic features, listed below.

Input variable 	Description
nvtx 	Number of primary vertices
beta 	fraction of jet tracks associated to the primary vertex
dR2Mean 	pT^2-weighted average square distance of jet constituents from the jet axis
frac01 	fraction of constituents' pT contained in the region dR < 0.1 around the jet axis
frac02 	fraction of constituents' pT contained in the ring 0.1 < dR < 0.2 around the jet axis
frac03 	fraction of constituents' pT contained in the ring 0.2 < dR < 0.3 around the jet axis
frac04 	fraction of constituents' pT contained in the ring 0.3 < dR < 0.4 around the jet axis
jetR 	fraction of jet pT carried by the leading constituent
jetRchg 	fraction of the jet pT carried by the leading charged constituent
majW 	major axis of the jet ellipsoid in the eta-phi plane
minW 	minor axis of the jet ellipsoid in the eta-phi plane
nCharged 	number of constituents
ptD 	pT-weighted average pT of contituents
pull 	magnitude of the pull vector

Data/MC Efficiency & Mistag Scale Factors

The PileUpJetID efficiency scale factors (SF) are available for the three recommended working points (Loose, Medium & Tight) and for each Ultra-Legacy era (UL2016 APV, UL2016 nonAPV, UL2017 & UL2018). In MC, we define AK4 CHS jets that are geometrically matched (ΔR < 0.4) to AK4 Gen jets to be HardScatter jets (HS-jet). The geometrical matching to AK4 Gen jets is to ensure that the SFs are applied for real jets (i.e jets from the Hard Scatter vertex). Jets failing the matching criterion are considered PileUp jets.

HOW TO USE THE SFs IN YOUR ANALYSIS ? : We recommend to use a procedure similar to what is done for applying b-tagging scale factors: https://twiki.cern.ch/twiki/bin/view/CMS/BTagSFMethods (method 1.a).

Efficiency Scale Factors

The SFs should be applied for any AK4 CHS jet in MC that passes the PileUpJetID and is also labelled as a HardScatter jet .

The SF’s are binned in jet η and pT bins:

    Jet η bins : 0<η<1.479, 1.479<η<2.0, 2.0<η<2.5, 2.5<η<2.75, 2.75<η <3.0, 3.0<η<5.0 and the corresponding negative η bins.
    Jet pT bins: 20-25, 25-30, 30-40, 40-50 in GeV. 

It is highly recommended for analyzers to read the efficiency SFs that are stored in JSON format using the correction-lib interface (Github). The SF's were merged to the jsonPOG-integration Gitlab repository (Gitlab, MR) and an example code on how to access them using correction-lib interface can be found here. The SFs are also available in ROOT's 2D histograms (TH2) stored in the root file attached with this twiki (PUID_106XTraining_ULRun2_EffSFandUncties_v1.root).

The efficiency SFs were presented and approved in this JMAR meeting: https://indico.cern.ch/event/1118864/#6-pileup-jet-id-sf-ul16apv-ul1

Mistag Scale Factors

There are no mistag scale factors available.
