Muon Recommendations For Analysis¶

This page provides a comprehensive overview of the recommendations for muon selection, isolation, and momentum assignment. For corrections and scale factors for these selections, see the Corrections page.

⚠ Note that this page covers Run 2 UL and Run 3 recommendations. For information on Run 2 pre-UL and Run 1 analysis, see this Twiki. However, be aware that the usage of pre-UL samples and data is strongly discouraged and those samples are no longer maintained by the POG.
Muon Selection¶

The muon reconstruction in CMS is optimized for maximum efficiency. The collection of reconstructed muons therefore contains muons from a large variety of sources, including potentially misreconstructed muons. A muon identification requirement is therefore necessary to select only those muons relevant for a given analysis. The choice of muon ID must be evaluated by each analysis for their needs.

The Muon POG supports a wide variety of muon ID selections, which are directly accessible in the different data formats (RECO/AOD; MiniAOD, nanoAOD).

Please note that in nanoAODs the Muon collection is preselected with some basic requirements:
pt > 15 || (pt > 3 && (passed('CutBasedIdLoose') || passed('SoftCutBasedId') || passed('SoftMvaId') || passed('CutBasedIdGlobalHighPt') || passed('CutBasedIdTrkHighPt')))
i.e., muons below 3 GeV are discarded, and those between 3 and 15 GeV are kept only if they pass one of the cut-based IDs.
Particle-flow (PF) Cut-Based IDs¶

The following general-purpose selectors define some simple working points points that are generally good for most use cases, and are consistent with PF selection of other objects in the event.
Loose Muon ID¶

Particle identified as a muon by the Particle-Flow event reconstruction, and that is also reconstructed either as a global-muon or as an arbitrated tracker-muon. Studied in MUO-10-004. This identification criteria is designed to be highly efficienct, for prompt muons, as well as from muons from heavy and light quark decays. Please consider complementing it by applying impact parameter cuts is used in analyses with prompt muon signals.

Medium Muon ID¶

Loose muon (i.e. PF muon that is either a global or an arbitrated tracker muon) with additional track-quality and muon-quality requirements. Described in this presentation by C. Botta & G. Petrucciani. This identification criteria is designed to be highly efficienct for prompt muons and for muons from heavy quark decays. Please consider complement it by impact parameter cuts on top of it, if you plan to use it to recostruct signatures with prompt muon decays.

In C++, the Medium ID selection can be implemented as follows.

bool isMediumMuon(const reco::Muon & recoMu)
   {
     bool validFracionThreshold=((272728 >= iEvent.run() && iEvent.run() >= 278808)? 0.49 : 0.8)

      bool goodGlob = recoMu.isGlobalMuon() &&
                      recoMu.globalTrack()->normalizedChi2() < 3 &&
                      recoMu.combinedQuality().chi2LocalPosition < 12 &&
                      recoMu.combinedQuality().trkKink < 20;
      bool isMedium = muon::isLooseMuon(recoMu) &&
                      recoMu.innerTrack()->validFraction() > validFracionThreshold &&
                      muon::segmentCompatibility(recoMu) > (goodGlob ? 0.303 : 0.451);
      return isMedium;
   }

Tight Muon ID¶

Global muon with additional muon-quality requirements. Studied in MUO-10-002 and MUO-10-004; widely used in physics analyses. Tight Muon ID selects a subset of the Particle-Flow muons.

Note that the tight muon ID exhibits an inefficiency for muons with pT above 200 GeV, which increases with muon pT. It is therefore not recommneded for use in analyses where a significant fraction of muons has pt > 200 GeV. The high-pT muon ID should be used instead.

High-pT Muon ID¶

This selection aims to provide the best reconstruction of the muon track parameters for high-pT muons (pT > 200 GeV), without relying on external information in the event. In this high-pT region, the muon detectors can improve the momentum resolution of the inner tracker. This ID is a variant of the tight muon ID which avoids the inefficiency at high pT, at the cost of an increased fake rate. If the fake rate is found to be too high for a given analysis, the medium ID can be used at the cost of a few percent in efficiency.

The pT assignment as obtained from the TuneP algorithm can be used anyway, independently of the adopted selection. Anyhow it is recommended not to use it directly for analyses that make use of Particle-Flow AND rely on quantities computed on the basis of the PF muon pT (e.g. PF MET). In fact, when using Particle-Flow the muon pT assignment can be further adjusted on the basis of the global event description. In this case, it is therefore advisable to stick with the estimation of the muon pT made by PF.

In-time Muon Selector¶

This selector is designed to discard out-of-time muons. You can quickly check if a muon is on time using the corresponding flag. If available, this selector trusts the RPC time, otherwise it takes the value calculated from the DT/CSC. This selector rejects about 0.08% of the muons with a mis-tagging efficiency of 0.000002%. For analyses using muon::CutBasedTightId out-of time muons should not be an issue, for looser muon selections it might be an issue. More details can be found in this talk by Piotr Traczyk.

Can be accessed for RECO or PAT muons using this function:
Data Format 	ID evaluation
reco::Muon (RECO/AOD) 	bool outOfTimeMuon(const reco::Muon& muon);
pat::Muon (MiniAOD) 	bool outOfTimeMuon(const pat::Muon & patMu);
NanoAOD 	Muon_inTimeMuon
Multivariate discriminants (MVA IDs)¶

Several discriminants based on MVAs have been developed, targeting different use cases.
Soft Muon MVA¶

The soft muon MVA is a Boosted Decision Tree (BDT) has been initially developed at the beginning of Run 2 for the Bmm4 analysis, and aims at reducing the fake rate from hadrons for low pT muons originating from B hadron in the barrel. It consists of a BDT trained for global muons, with pT > 4 GeV and |η| < 1.4, coming from Bs/d mesons.

The Run 2 version is documented at this link.

For Run 3, a new version has been trained with much looser phase space restrictions (pT > 2 GeV and |η| < 2.4). It is documented in MUO-24-001

Obsolete/deprecated IDs¶
Lepton MVA¶

The lepton MVA has been developed in the context of the ttH multilepton and some SUSY multilepton analyses. It was trained to discriminate fake muons in a semileptonic ttbar sample (mainly leptonic B decays) against prompt leptons in a ttH sample. There is a twiki documenting the main features of the MVA link, and there you can also find links to talks on the performance of some of the working points. You can find all the details of the most recent training in the AN supporting the ttH multilepton (AN2018_098).

This variable was present as Muon_mvaId in nanoAODs up to v10 and was then removed. This variable stores the output of a selector applied to PAT muons. The possible values are 1=MvaLoose, 2=MvaMedium, 3=MvaTight, 4=MvaVTight, 5=MvaVVTight. The score was not saved, as the similar, improved Muon_mvaTT (see above) was present. It was removed after NanoAOD v10 and replaced by the Muon MVA.
Muon Isolation¶

Many muons are produced from the decay of both light- and heavy-flavor hadrons in jets. For analyses targeting prompt muon production, these can be rejected by using isolation criteria. Here again, a set of different options are supported by the POG from which each analysis can pick according to their needs.

Note: If the ttH/PromptMuon MVA is used, no further isolation selection should be applied.
Particle-Flow isolation¶

PF-based combined relative isolation with Δβ corrections (see here) for PU mitigation, uses a (ΔR) cone size of 0.4 and is defined as follows:

    (∑pT(ch.had from PV) + max(0, ∑ET(neut.had) + ∑ET(phot) − 0.5*∑pT(ch.had from PU)))/pT(μ)

(mu->pfIsolationR04().sumChargedHadronPt + max(0., mu->pfIsolationR04().sumNeutralHadronEt + mu->pfIsolationR04().sumPhotonEt - 0.5*mu->pfIsolationR04().sumPUPt))/mu->pt()

Mini Isolation¶

Miniisolation allows to recover efficiency when muons are produced in the decay chain of a boosted object. In such cases, it is likely that, when the boost is large, the muon overlaps with a jet produced in the same decay chain, failing a standard isolation cut. Miniisolation is constructed by defining a cone whose radius varies with the pt 0.2 and 0.05. Isolation is then calculated for that muon on that cone, reducing the probability of the overlap for more boosted topologies. More information on the definition of miniiso and its performance can be found here. Four working points are provided in the standard selectors, which are calculated using effective area corrections.

Muon Momentum Assignment¶

Muon momentum is measured using multiple algorithms based on varying amount of information. Standalone muons use only muon system information, tracker muons only the tracker hits. Global muons perform a combined fit to all signal in both tracker and muon system. For high-pT muons additional algorithms are used to mitigate the effects of bremstrahlung and showering of the muons in the muon system, see MUO-17-001.

Out of all these options, the best track fit is selected for the final momentum assignment. Two options are availabe at the pat::Muon level:

    muon.muonBestTrack().pt() returns the pT of the track selected to be the best measurement of the muon parameters (including PFlow global information)
    muon.tunePMuonBestTrack().pt() retuns the pT of the track selected to be the best measurement of the muon parameters (from muon information alone)

The first option is recommended for all analyses relying on particle flow information (and is the default muon momentum available as just muon.pt(), while the second option is mostly for high-pT muon analyses that don't use particle flow information.

In NanoAOD, the first option is accessed simply as Muon_pt, while the second is available as Muon_pt * Muon_tunepRelPt.
Basic Momentum corrections¶

The momentum assignment is affected by biases resulted from the imprecise knowledge of the detector material, magnetic field, and alignment. For high-pT muons, usually not enough statistics is available to derive corrections for these effects, and systmatic uncertainties are assigned to cover them, see here.

For medium pT muons, momentum corrections are available that correct the momentum scale in data and the scale and resolution in MC to bring them in agreement. These corrections are usually not required for analyses that are not senstive to percent-level effects in the muon momementum assigned, but recommended in all other cases. A dedicated correction for low-pT muon is being prepared.


Muon correction recommendations¶

There are two general types of corrections that need to be considered in an analysis: First, there are corrections to the muon efficiencies for reconstruction, identification, isolation, and trigger in form of Data/MC scale factors that need to be applied to muons in MC events. Second, corrections can be applied to correct the muon momentum assignment, both in data and MC.

The recommended corrections differ based on muon momentum and are usually provided for three pT regimes: Low pT (pT < 30 GeV), medium pT (30 GeV < pT < 200 GeV), and high-pT (pT > 200 GeV). Note: This does not imply that different sets of corrections are supposed to be applied within one analysis, depending on muon pT. Rather, analysts are supposed to pick the corrections corresponding to the pT ranges that covers the bulk of their muons.
Note on correlations¶

To keep the overall uncertainties as small as possible, systematic and statistical uncertainties on the scale factor measurement are treated as separate sources of systematic uncertainty. See recommendations from TOP PAG for details: https://twiki.cern.ch/twiki/bin/view/CMS/TopSystematics#Muon_identification_isolation_mo

The main takeaway are the following recommendations regarding the correlation of uncertainties among data taking periods:

    Systematic uncertainties on the scale factor measurements should be considered correlated among data taking periods.
    Statistical uncertainties on the scale factor measurement should be considered uncorrelated among the different years.

L1 Trigger prefiring¶

Run2:

Incorrect assignment of the muons to the LHC bunch crossings in the L1 trigger can lead to a loss of trigger efficiency, an effect known as "trigger prefiring".     If you are using tight or high pT ID in your analysis, those dxy and dz cuts are part of the selectors.     If you are using tighter dxy and dz cuts to select your signal, you need to perform the same MC check as decribed above, for the values of dxy and dz used in your analysis.
    If you are using medium or loose ID in your analysis, those dxy and dz cuts are not part of the selectors, so in principle it does not introduce any bias.

High pT: Momentum Scale¶

Momentum assignment of high-pT muons relies more and more on the muon system so that we cannot fully rely on the scale bias measured at Z peak with Rochester method, for which only the tracker information are used in the momentum determination. Bias in the muon system such as misalignment, are not measured with the standard method. Therefore, high-pT muon dedicated momentum scale measurement, namely Generalized Endpoint (GE) method, have been performed. The GE method injects a range of additive biases (κb) in different bins to the simulation and minimize the difference between data in the q/pT distribution. The value for which the simulated distribution reproduced the data one, correspond to the scale bias. A detailed description (containing also Legacy results) can be found in AN-2018/008.

Note: the corrections described in this section only apply to muons with transverse momentum larger than 200 GeV. Do not mix up the GE corrections with the scale and smearing corrections applied at medium pT.

Note: analyses that include muons in a very large pT spectrum (across the 200 GeV threshold) can treat the muon momentum scale following two approaches, depending on the specific details of the analysis:

    If muons with pT < 200 GeV represent a significant fraction of the analyzed sample or, more generally, have a significant impact on the analysis sensitivity, it is recommended that both the medium pT (so-called Rochester corrections in Run2) and GE methods are considered, as follows:
        muons with pT < 200 GeV are corrected using the medium pT scale and smearing corrections, assigning a systematic uncertainty from variations of the individual components of the correction.
        muons with pT > 200 GeV are left uncorrected, and their systematic uncertainties are computed using the GE method (see below).
    If muons with pT < 200 GeV represent a small fraction of the sample and have a negligible impact on the final results, then the analyzers can choose to skip the medium pT corrections, leave all muons uncorrected, and only apply systematic uncertainties from the GE method to all muons, including those with pT < 200 GeV (see below). In case of doubts, e.g. if the impact of low-pT muons is still unclear, it is advisable to follow the first approach (i.e. Rochester at low pT and GE at high pT).

Note: in addition, for all analyses having muon signal candidates above 500 GeV, we recommend an additional sanity check: manually shift the pT of the muon using the scale biases measured from the medium pT corrections and/or GE method and check the effect on the analysis results. This check is really important, because the systematic uncertainties described above do not cover in case of major scale bias in data on a given event.

High pT: Momentum Resolution¶

The momentum resolution in simulation is adjusted to match that observed in data through a smearing procedure that is applied consistently across datasets. In general, the agreement between data and simulation is first evaluated as a function of kinematic variables such as pseudorapidity. In regions where the resolutions are already consistent, no modification is applied, while in regions where the simulation shows better resolution than data, an additional smearing is introduced. This is implemented by redefining the momentum with a stochastic term, where the magnitude of the smearing is governed by a parametrized resolution function that depends on the particle momentum and detector region. The functional form of this parametrization remains fixed, while its coefficients are determined separately for each dataset and are listed in the following.

Systematic uncertainties associated with this procedure are estimated by varying the resolution within its uncertainty, propagating the resulting changes through the full analysis chain, and taking the deviation from the nominal result as the corresponding systematic effect.

More precisely, the systematic on the muon momentum resolution is estimated by varying the fit window, the number of bins, and the fit function when extracting the Z mass resolution in the above method.
